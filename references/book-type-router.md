# Book-Type Router

Use this reference during L0, before extracting claims. The purpose is to choose the right compression objective and to stop the practical-book workflow when it would create false confidence.

## Routing table

| Book type | Primary objective | Allowed treatment | Stop or switch when |
|---|---|---|---|
| Practical/self-help, habits, productivity, management | Fast problem solving and method selection | L0–L5; compress repetition and motivation; keep selected claims, executable methods, and source anchors | New passages add no decision, mechanism, or action value; label remaining chapters deferred |
| Textbook/course/manual | Ordered coverage and prerequisite clarity | Keep a chapter scaffold, definitions, dependencies, exercises, and stated exceptions; use cards as an index, not a substitute for coverage | The reader needs exam-level completeness, derivations, or prerequisite teaching; switch to a full curriculum/outline workflow |
| Research monograph or evidence-heavy nonfiction | Argument and evidence traceability | Map claims, methods, data, citations, limitations, and competing explanations; preserve citation context | The primary sources are not available or the task asks for an evidence synthesis; switch to a research-review workflow and do not upgrade second-hand reports |
| Law, medicine, safety, finance, or other high-stakes guidance | Safe orientation, not personalized advice | Summarize scope, terminology, questions for a qualified professional, and source locations; retain caveats verbatim where possible | A card could be read as diagnosis, treatment, legal advice, or a decision rule for a specific person; stop actionable distillation |
| Fiction, memoir, biography, narrative history | Story/theme orientation | Use a chapter or character map only if the user asks; preserve plot context and distinguish narrator from fact | The request is for practical methods or factual evidence; this skill is the wrong router |
| Mixed or hybrid book | Match each section to its local objective | Split by chapter/section type; apply the strictest evidence and safety rule to the affected part | A single blended card would erase the difference between story, opinion, and evidence; keep separate paths |

## Practical-book eligibility test

Proceed with the full workflow only when most answers are yes:

- The book contains repeatable principles, decisions, behaviors, or checklists.
- The reader has concrete problems or interests that can become navigation questions.
- Information density is uneven enough that selective reading saves time.
- The source can be preserved and its claims can be anchored to chapters or sections.
- Omitting low-value passages will not change the meaning of selected claims.

If only the first two answers are yes, create a small orientation map and a source reading list rather than pretending to have a full distillation.

## Stop conditions and safe fallback

Stop adding cards and report the reason when any of these holds:

1. **Source integrity failure** — missing chapters, corrupted extraction, unresolved OCR, or no stable locator. Keep the source audit and mark claims as unverified.
2. **Context loss** — a qualification, definition, counterexample, or dependency was removed and would change interpretation. Restore the context or link directly to the source instead of compressing further.
3. **No transferable action** — a passage is only motivational, autobiographical, or repetitive. Leave it in the original source if useful, but do not manufacture a method card or copy it into a retained text layer by default.
4. **High-stakes escalation** — a reader could act on a personalized legal, medical, safety, or financial recommendation. Switch to safe orientation and professional-review prompts.
5. **User asks for completeness** — if the user wants every chapter, all definitions, or exam-level mastery, switch to a complete-outline or curriculum workflow. Do not claim that a selective package is comprehensive.
6. **Evidence mismatch** — the book invokes research but provides only an uncheckable paraphrase. Label it as a reported claim, preserve the citation context, and avoid causal or numerical certainty.

## Handling low-density books

Start with the table of contents, preface, conclusion, and chapter summaries. Cluster repeated claims before writing cards. Stop when the next cluster only restates an existing proposition, changes tone but not mechanism, or adds a story without transfer value. The output should explicitly list what was selected and what was intentionally deferred; this is a scope decision, not a quality defect.

## Human review gates

Ask for human review when the type is ambiguous, when the source is incomplete, or when the reader's intended use changes the safety bar. The agent may produce a navigation map and source audit while waiting, but must not fill the gap with invented evidence or advice.
